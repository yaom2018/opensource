## 文法（目標：4条）

### 文法条1: ～に応じて（第6課）
- [ ] 文法名：～に応じて
- [ ] 接続：名詞＋に応じて
- [ ] 意味：按照…；根据…（根据前项的情况做出相应的变化或应对）
- [ ] 例文：
  - このレストランは季節に応じてメニューが異なる（这个餐厅按照季节不同菜品也不同）
  - 語学力に応じて、クラスを分けます（按照语言水平分班）
  - 収入に応じて、支出を考えなければならない（必须按照收入考虑支出）
- [ ] 理解度：[  /5]
- [ ] 備考：「～によって」と類似するが、「に応じて」は"対応・適応"の意味がより強い。「に従って」との違い：「に応じて」＝状況に合わせて変化させる、「に従って」＝それに沿って行動する

### 文法条2: ～ていられるのは…からだ（第6課）
- [ ] 文法名：～ていられるのは…からだ
- [ ] 接続：動詞テ形＋いられるのは、…からだ
- [ ] 意味：能够保持…的原因是…（表示某种状态之所以可能，是因为后述原因）
- [ ] 例文：
  - こんなときに私が落ち着いていられるのは、心の中のことは大体51対49くらいのところで勝負がついていることが多いと思っているからである（这种时候我能够保持平静的原因是，心里较量一般是在51比49的地方已经分出了胜负）
  - 彼が冷静でいられるのは、多くの経験を積んできたからだ（他能保持冷静是因为积累了丰富的经验）
- [ ] 理解度：[  /5]
- [ ] 備考：「～ていられる」＝「～ている」の可能形。後項は必ず原因理由（「からだ」「ためだ」）。書面語言い回し。

### 文法条3: ～と思いきや（第7課）
- [ ] 文法名：～と思いきや
- [ ] 接続：普通体（動詞／い形容詞／な形容詞／名詞）＋と思いきや
- [ ] 意味：本以为…结果没想到…（表示与预想相反的结果）
- [ ] 例文：
  - 今日は暑くなると思いきや、むしろ寒いくらいです（本以为今天会热，结果倒不如说是有些冷）
  - 海辺の町で育ったと聞いていたので、さぞかし泳ぎが上手だろうと思いきや、水に浮くこともできないらしい（听说他在海边城市长大，本以为游泳很好，没想到连浮水都不会）
  - 「考えてみます」と言われたので、了承されたと思いきや、実はそれは「お断りします」という意味だった（跟我说"考虑考虑"，本以为是知道了，结果意思是"拒绝"）
- [ ] 理解度：[  /5]
- [ ] 備考：前項に「さぞかし」「だろう」など推測表現がよく来る。書面語。

### 文法条4: ～のみならず（第7課）
- [ ] 文法名：～のみならず
- [ ] 接続：名詞／動詞普通形＋のみならず
- [ ] 意味：不仅…（而且也…）；非但…
- [ ] 例文：
  - 中小企業のみならず、大企業でも経費の削減をしている（非但中小企业，大企业也在削减经费）
  - このストールは春夏のみならず、秋冬にも重宝します（这条围巾不仅春夏，秋冬也非常实用）
  - 本工房の陶器のみならず、交流のある作家の器も展示しております（不仅本工作室的陶器，有交流的作家的作品也在展出）
- [ ] 理解度：[  /5]
- [ ] 備考：「のみ」＝文語の「だけ/ばかり」、「ならず」＝「なく」の文語形。「～だけでなく」「～ばかりでなく」より正式。後項によく「も」が来る。
