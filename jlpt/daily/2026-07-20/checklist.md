### 文法条1: ～ばかりに（第14課）
- [ ] 文法名：～ばかりに

- [ ] 接続：動詞/形容詞普通形＋ばかりに（名詞/な形容詞＋である＋ばかりに）

- [ ] 意味：全是因为…才…（表示正因为某个原因导致了不好的结果，含遗憾、后悔的语气）

- [ ] 例文：
  - 私が遅刻したばかりにみんなに迷惑をかけてしまいました（全是因为我迟到了，给大家添了麻烦）
  
  - 彼の一言を信じたばかりに酷い目にあった（全因为相信了他的一句话，倒了大霉）
  
    ​												ひどいめに　あった
  
  - 外国人であるばかりに、アパート探しに散々苦労した（全因为是外国人，找房子非常辛苦）
  
    さんざんくろうした
  
    
  
- [ ] 理解度：[  /5]

- [ ] 備考：後項は必ず消極的・悪い結果。「だけに」との区別：ばかりに＝消極結果＋後悔、「だけに」＝因果強調（プラスもマイナスも可）

**日本に来たばかりです。**

> 刚来日本。



### 文法条2: ～だに（第14課）
- [ ] 文法名：～だに
- [ ] 接続：動詞辞書形＋だに／名詞＋だに
- [ ] 意味：连…都…；只是…就…（表示仅凭某事就足以产生强烈的感受）
- [ ] 例文：
  - あんな結末を迎えたなんて、思い出すだに悔しい（迎来了那样的结局，想起来就不甘心）
  - 世界遺産が火災に見舞われたと聞くだに心が痛む（世界遗产遭遇火灾，只是听就心痛）
  - 生で見る相撲の試合はこんなに迫力があるなんて、想像だにしなかった（现场看的相扑比赛这么有魄力，根本没有想象到）
- [ ] 理解度：[  /5]
- [ ] 備考：文語残存表現、書面語感が強い。思考・知覚動詞とよく共起（思い出すだに、聞くだに、想像だに、考えるだに）。「想像だにしなかった」＝まったく想像しなかった

### 文法条3: ～や否や（第6課）
- [ ] 文法名：～や否や
- [ ] 接続：動詞辞書形＋や否や
- [ ] 意味：刚一…就…；一…立刻…（表示前后动作几乎同时发生，强调速度快）
- [ ] 例文：
  - 真っ暗なトンネルを抜けるや否や、見渡す限りの海が目に入った（刚一穿过漆黑的隧道，一望无际的大海就映入了眼帘）
  - バスが止まるや否や、飛び降りた（公交车刚一停就跳下车）
  - 「美味しい生活」が登場するや否や、それはたちまち話題をさらった（"美味生活"一登场，立刻成了热门话题）
- [ ] 理解度：[  /5]
- [ ] 備考：後項によく「たちまち」「すぐ」などの素早さを表す語が来る。書面語。「〜なり」と類似するが、「や否や」は別主体の動作も可。

### 文法条4: ～ものか／～もんか（第6課）
- [ ] 文法名：～ものか／～もんか
- [ ] 接続：動詞/い形容詞/な形容詞/名詞の普通形＋ものか
- [ ] 意味：怎么可能…呢！/决不…！（表示强烈否定、反问语气）
- [ ] 例文：
  - 相手にするものか（谁理他呀！）
  - そんなことがあるものか（怎么可能有那种事啊！）
  - あんなことに負けるものか（怎么可能输给那种事！）
- [ ] 理解度：[  /5]
- [ ] 備考：「ものか」は書面語/フォーマル、「もんか」は口語。相手の言ったことへの強い否定や不服・ありえないという気持ちを表す。丁寧体は「ものですか」。
