## 文法（目標：4条）

### 文法①：～ば～たで（即便…也是…）【第8課】
- [x] 文法名：～ば～たで

- [x] 接続：動詞ば形＋同一動詞た形＋で

- [x] 意味：即便…也是…（表示即使做了前项，也还是会有后项的问题）

- [x] 例文：
  - 庭付きの家を買えば買ったで、困ることがある（即便买了带院子的房子，也有难处）
  
    にわつきのいえ　を　かえばかったで、　こまることがある
  
  - 行けば行ったで　疲れる（即便去了也是累）
  
    いけばいけったで　
  
  - 彼が来れば来たで、気を遣う（他来了也有来了的麻烦）
  
    かれが　くれば　きたで、　きをつかう
  
- [x] 理解度：[ /5]

- [x] 備考：同一動詞の仮定形＋過去形でワンセット。「たで」は口語で「ったで」になる

因为这是固定句型：

> **Vば Vたで**

例如：

- 行けば行ったで（いけば いったで）
- 食べれば食べたで（たべれば たべたで）
- 買えば買ったで（かえば かったで）
- 結婚すれば結婚したで（けっこんすれば けっこんしたで）

它的模式就是：

> **假设形（ば） + 过去式（た） + で**

虽然看起来有点奇怪，但这是日语的固定表达，不要理解成「如果买了就买了」，而要整体记成：

> **VばVたで = 做了有做了的麻烦／做了也有做了的问题。**



### 文法②：～なら～で（就是…也有…）【第8課】
- [x] 文法名：～なら～で

- [x] 接続：名詞＋なら＋同一名詞＋で

- [x] 意味：就是…也有…的问题；既然是…也要…

- [x] 例文：
  - 警察なら警察で、びしっと言わなきゃ（就是警察，也要严厉批评）
  
  - 来たなら来たっで、連絡ぐらいしろよ（都来了，就联系一下吧）
  
    きたならきたって、れんらくぐらいしろよ
  
    
  
  - 妻なら妻で、別の悩みがある（妻子也有妻子的烦恼）
    べつになやみがある
  
- [x] 理解度：[ /5]

- [x] 備考：「～ば～たで」との違い：「～ば～たで」は仮定条件、「～なら～で」は確定条件。口語では「なら…っで」

### 文法③：～たところで（即便…也…）【第8課】
- [x] 文法名：～たところで

- [x] 接続：動詞た形＋ところで

- [x] 意味：即便…也…；就算…也…（让步，后项多为否定或消极）

- [x] 例文：
  - いくら怒っ　たところで、仕方がないでしょう（再怎么生气也没办法吧）
  
    いくら　おこった　ところで、しかたがないでしょう
  
  - 今さら駆けつけ　たところで、もう間に合わないと思う（即便现在赶去，也来不及了）
  
    いま　さら　かけつけ　たところで、　
  
  - 無理し　たところで、仕事が早く終わる　わけではない（勉强自己工作也不会早结束）
  
    むりしたところで、
  
- [x] 理解度：[ /5]

- [x] 備考：「～ても」より「即便做了也没用」的语感更强。后项多为否定/消极

### 文法④：～にしても（不管是…/即使…也…）【第8課】
- [x] 文法名：～にしても
- [x] 接続：名詞／動詞普通形＋にしても
- [x] 意味：不管是…还是…；即使…也…
- [x] 例文：
  - 石油にしてもガスにしても決して無限ではない（石油也好燃气也好，绝不是无限的）
  - するにしても、しないにしても、さっさと決めてください（做还是不做，赶紧决定）
  - 値段が高いにしても、品質はいい（就算贵，品质也好）
- [x] 理解度：[ /5]
- [x] 備考：「～にしろ」「～にせよ」と同じ意味で、より硬い表現。「AにしてもBにしても」で列举
