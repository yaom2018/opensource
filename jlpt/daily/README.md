1. **判断平日/周末**：

   - 土〜日：周末模式（2-4h）

2. **生成目标**：
   - 平日：Anki 15+15 + 语法2条 + 听读
   - 周末：Anki 25+25 + 语法3-4条 + 阅读 + 精听

3. **关联文件**：
   - N1单词笔记.md
   - N1语法笔记_*.md

   - 薄弱点.md
