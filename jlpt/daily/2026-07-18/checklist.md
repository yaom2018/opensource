## 文法（目標：3-4条）

### 文法条1: ～にして
- [x] 文法名：～にして
- [x] 接続：名詞＋にして
- [x] 意味：
  ① 到了…才…（到达某个阶段才发生）
  ② 连…都…（表示程度）
  ③ 一边…一边…（表示并列）
  ④ 即便…也…（にしても形式）
- [x] 例文：
  - 40歳にしてようやく自分の道を見つけた（①）
  - この試験は四回目にしてようやく合格できた（①）
  - 学問とは厳謹にして至誠な態度で向き合うべきです（③）
- [x] 理解度：[1-5]

### 文法条3: ～はもちろん／～はもちろんのこと
- [x] 文法名：～はもちろん
- [x] 接続：名詞＋はもちろん（のこと）
- [x] 意味：不用说…；…自不必说
- [x] 例文：

- [x] 理解度：[1-5]
