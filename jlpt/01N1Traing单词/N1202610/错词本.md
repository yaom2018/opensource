# N1 错词本（N1語彙1-1000）

> **这个文件是主战场。** 每天的流程：
> ① 看 `10天背诵/DayXX.md` 的**第一节学习页**（字 + 读音 + 日语释义 + 例句）
> ② 做第二节的 **2 选 1 盲测** 100 题 → ③ 对答案
> ④ 选错的词登记到下面「三、错题台账」→ 当天**回炉**（遮住选项，只看句子写出「字 + 读音」）
> ⑤ 按 1 / 3 / 7 天重测。**已经会的词不用再花时间，反复攻的只有错题。**
>
> 复习日（Day+1 / +3 / +7）顺序反过来：**先做题、再看学习页**——先测出来的错才是真错。

---

## 一、回炉三步法（每个错词都过一遍）

1. **填空**：看句子（不给选项），写出单词 + 读音 —— 写不出来说明还没记住
2. **出声**：读例句 3 遍，把搭配一起读出来（～に値する / ～に欠ける / ～を問わず）
3. **分辨**：说出它和「易混词」的差别 —— N1 語彙考的就是"从近义词里挑最合适的那个"

错因分四类，登记时写上：**①读音 ②近义混同 ③词性活用 ④搭配惯用**
①只抄写 + 朗读；②要做对照表；③要造句；④要整块背搭配。
